# AtomicPay

### Fault-Tolerant Transaction Processing

AtomicPay is a prototype that simulates the core transaction-processing
part of a payment system.

The project focuses on understanding how concurrent transactions can
be processed safely and how consistency can be maintained when failures
occur.

## Objectives

- Simulate concurrent payment transactions
- Study transaction consistency
- Apply OS concepts such as threads and synchronization
- Apply DBMS concepts such as transactions, locking and recovery
- Simulate failures and observe recovery
- Monitor transaction and system states

## Planned Technologies

- Java
- Spring Boot
- PostgreSQL
- REST APIs
- HTML, CSS and JavaScript
